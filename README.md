# 📊 Glassdoor Salary Prediction

## 🚀 Overview

This project builds a machine learning model to predict job salaries using the Glassdoor dataset.

## 📌 Problem

Accurately estimating salaries based on job-related features like skills, experience, and role.

## 🛠️ Tech Stack

* Python
* Pandas, NumPy
* Scikit-learn
* Matplotlib, Seaborn

## ⚙️ Workflow

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Model Training & Evaluation

## 📈 Result

Built regression models to predict salaries with optimized performance.

## 📎 Dataset

Glassdoor dataset
